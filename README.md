# 객성록 HUD (ST-Gaekseong)

현대 동양 크툴루 헌터 시뮬봇 **「객성록 — 한성 퇴마록」** 전용 SillyTavern 확장입니다.
체력·이성·오염·계약·금기·변이를 **확장이 직접 계산**하고, 상태창(HUD)·판정·권능·입적(캐릭터 생성)을 제공합니다.

AI는 응답 끝에 이번 턴의 **변화량만** 적습니다. 숫자는 확장이 지킵니다.

```
<state>
hp: -8
san: -5
cor: +12
foe: 붉은 우산 여자 | 70 | 젖지 않은 사람을 싫어함
</state>
```

## 설치

1. SillyTavern → 확장(블록 아이콘) → **Install extension** → 이 저장소 주소 입력
   `https://github.com/YOUR-ID/ST-Gaekseong`
2. 캐릭터 카드 `객성록.png`를 가져옵니다. 처음 열 때 **캐릭터 정규식 허용**을 누르세요(정규식 5개가 카드에 들어 있습니다).
3. 로어북은 카드에 내장되어 있습니다. 따로 쓰려면 `객성록_로어북.json`을 월드인포로 가져오세요.
4. 채팅을 열면 **입적** 창이 뜹니다. 이름·신분·배경·첫 번째 객성을 정하고 첫 행동을 보내면 시작됩니다.

> 확장은 기본적으로 **객성록 카드에서만** 켜집니다(카드의 `extensions.gaekseong` 표식). 다른 카드에 쓰려면 설정에서 "모든 캐릭터에서 사용"을 켜세요.

## 화면 구성

| 위치 | 기능 |
|---|---|
| ☯ | 상태 시트 — 상태 · 계약 · 변이·광기 · 인연 · 기록 · 관리 |
| 이름 | 누르면 HUD를 한 줄로 접기/펴기 (모바일용) |
| 🎲 | 판정 — 육체/감지/주술/정신/교섭/은신 × 쉬움~절망, d100 |
| ⚡ | 권능 발동 — 약(오염 +4) / 중(+10) / 강(+22), 임계점 경고 |
| ▾ | 펼치기 — 장소·자금·의뢰·저주·변이·광기 칩 |
| 금기 칩 | 누르면 오늘의 금기 이행을 기록. ● 노랑 깜박임 = 미이행 |

메시지마다 그 턴의 변동(체력 −8, 오염 +12, 새 인연, 변이 발현…)이 작은 카드로 붙습니다.
의뢰·전투 중에는 AI가 낸 선택지가 버튼이 되고, 이성이 50 이하로 떨어지면 **⟨이질⟩** 선택지가 섞입니다.

## 규칙 요약

- **오염 25 · 50 · 75%** 를 넘을 때마다 영구 변이 1개, **100%** 객성화 엔딩
- **이성 75** 불면 · **50** 환각(광기 1개, `<hallu>` 환청 표기, ⟨이질⟩ 선택지) · **25** 붕괴(광기 1개, 화면·글자 일그러짐) · **0** 광인
- **체력 0** 빈사 → HUD에서 "객성의 손을 잡는다"(체력 35, 오염 +25, 횟수마다 +10)
- **금기**: 날짜가 넘어갈 때(`day: +1`) 그날 이행하지 않은 금기마다 이성 −8 · 오염 +6 · 저주(하루). 서사에서 대놓고 어기면(`taboo: 이름 = 어김`) 이성 −10 · 오염 +10
- **판정 보정**: 중상 시 육체·은신 −15, 환각/붕괴 시 감지·정신·교섭 −10/−20, 주술은 오염 5%당 +1(오염될수록 주술이 잘 듣는다), 변이마다 감지 +5, 저주마다 −5. 이성 25 이하이면 대실패 범위 91~100
- **거꾸로 선 아이** 계약자는 하루 한 번 실패한 판정을 되감을 수 있음(오염 +8)
- **구멍 난 하늘**의 권능 오염은 1.5배

## 작동 방식 (스와이프·수정에 강한 이유)

- 상태는 저장된 값이 아니라 **채팅 처음부터 모든 AI 메시지의 `<state>`를 다시 읽어** 계산합니다. 스와이프, 수정, 삭제를 하면 자동으로 맞춰집니다.
- 수동 조정(권능, 금기 이행, 시트 수정, 부활)은 채팅 메타데이터에 "몇 번째 메시지 시점"과 함께 기록되어 같은 순서로 재생됩니다.
- 변이·광기 추첨은 채팅 ID 기반 시드라 다시 계산해도 같은 결과가 나옵니다.
- 현재 상태는 `setExtensionPrompt`로 채팅 깊이 1(설정 가능)에 시스템 메시지로 주입됩니다. 월드인포 스캔에 포함되므로 `⟦모드:전투⟧`, `⟦이성2⟧`, 계약 이름, 장소 이름이 로어북 항목을 자동으로 켭니다.
- 프롬프트 정규식이 과거 메시지의 `<state>`·`<choices>`를 지워 토큰을 아낍니다.

## AI 출력 키

`hp` `san` `cor` `cash` — 부호 있으면 증감, 없으면 그 값으로 설정 (`cash: +30만` 가능)
`day` (+1 = 하루 경과) · `time` (새벽/아침/낮/저녁/밤/자정) · `loc` · `mode` (일상/의뢰/전투) · `rank`
`case: 의뢰명 | 진행` · `foe: 이름 | 남은형체% | 특징` (`없음`으로 해제)
`taboo: 계약명 = 지킴|어김` · `curse: +내용 / -내용` · `mutation: +이름 | 묘사` · `madness: +이름` · `bond: 이름 +1 | 메모`
한글 키(체력, 이성, 오염, 장소, 적, 금기, 인연…)도 인식합니다.

## 슬래시 커맨드

- `/gs-sheet` 상태 시트 · `/gs-new` 입적(이미 했으면 수정) · `/gs-roll 주술` 판정 창
- `/gs-set key=cor +10` 상태 직접 조정 (기록에 남고 시트에서 되돌릴 수 있음)

## 설정 (확장 패널 → 객성록 HUD)

사용 / 모든 캐릭터에서 사용 / 입적 창 자동 열기 / 연출 효과 / 글자 일그러짐 / 메시지 상태 카드(간단·게이지·숨김) / 선택지(의뢰·전투만·항상·끔) / 선택지 클릭 시(입력·바로 전송) / 주입 깊이 / **주입 프롬프트 보기**

## 문제 해결

- **상태 카드가 안 보이고 `<state>` 글자가 그대로 보임** → 캐릭터 정규식이 꺼져 있습니다. 정규식 확장에서 "객성록 ①~⑤"를 허용하거나 `regex` 폴더 JSON을 전역으로 가져오세요.
- **AI가 상태 블록을 빼먹음** → 설정의 "주입 프롬프트 보기"로 주입을 확인하고, 주입 깊이를 0으로 낮춰 보세요.
- **수치가 이상함** → 시트 › 관리 › "마지막 수동 조정 되돌리기", 또는 해당 AI 메시지를 수정하면 즉시 다시 계산됩니다.
- 그 밖의 오류는 브라우저 콘솔(F12)에서 `[객성록]`으로 시작하는 줄을 확인하세요.
